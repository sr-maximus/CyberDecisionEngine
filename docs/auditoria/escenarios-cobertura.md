# Cobertura del motor de escenarios

## Cobertura vigente

La plataforma conserva catálogos ATT&CK, D3FEND, ATLAS y DISARM para clasificación y referencia. La activación actual de posibilidades exige evidencia de la corrida y mantiene separados trigger, soporte, confianza, impacto y estado de validación.

| Dimensión | Cobertura |
|---|---|
| Catálogos de referencia | Disponible |
| Plantillas preventivas | 1.500 |
| Contrato ejecutable validado | Disponible |
| Definiciones ejecutables | 0 |
| Matriz de pruebas por definición | Exigida por contrato; 0 implementadas |
| Disparos por coincidencia textual aislada | No permitidos |
| Separación por organización/corrida | Conservada por `runId` y contexto |

La cobertura de framework no equivale a cumplimiento, ataque observado, incidente ni riesgo confirmado.
