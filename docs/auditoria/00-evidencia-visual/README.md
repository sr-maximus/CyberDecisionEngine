# Política de evidencia visual

Las capturas de interfaz y de informes se generan localmente con datos
sintéticos y no se almacenan en el repositorio público.

Una captura solo puede compartirse después de comprobar que no muestra:

- organizaciones o dominios analizados;
- usuarios, correos, contraseñas, hashes o códigos MFA;
- identificadores, fechas o rutas de corridas reales;
- métricas o evidencia operativa de terceros.

Para documentar una pantalla utiliza marcadores descriptivos como
`<organization-name>`, `<authorized-domain>`, `<run-id>` y `<measured-value>`.
La captura original permanece fuera de Git.
